二、系统架构
================================================================================

三层架构，前后端分离：

1. 用户交互层：Vue2 + Element UI
   - 沙盘游戏介绍（首页）
   - 心理健康智能预测
   - 聚类分析（群体聚类）
   - 异常检测（无监督异常检测）
   - 分析记录（历史记录查看）

2. 数据存储层：MySQL
   - 用户信息、沙盘数据、分析记录
   - 多模态特征以CSV文件持久化（9个CSV文件在 py/ai_service/data/）
   - 推理结果通过缓存机制提升响应速度

3. 模型处理层：Python FastAPI
   - AI分析服务独立部署
   - 完成8类多模态特征提取
   - 调用多视图融合图卷积模型
   - 实现心理健康预测、聚类分析与异常检测

还涉及：
- Redis：缓存依赖
- 聆心云：独立的3D在线数字沙盘平台（外部系统），通过跳转接入
  - 用户在聆心云中只能自己保存沙盘数据
  - 不能自动采集聆心云数据
  - 保存的数据可作为AI分析的数据来源

四、核心算法 - 多视图融合图卷积模型
================================================================================

4.1 整体流程
数据输入 → 8类特征视图 → 稀疏自编码器编码 → 视图MLP → 全局MLP → 对比学习 → 自适应加权融合 → 可学习图卷积 → 分类输出

4.2 八类特征视图
1. 统计视图（step.csv）：沙具数量、使用频率、操作次数
2. 类别视图（type.csv）：人物、动物、建筑、植物等沙具类别分布
3. 情感视图（emotion.csv）：沙具情感倾向或语义评分
4. 空间聚集视图（gathering.csv）：密度、聚集程度、离散程度、区域分布
5. 多样性视图（variety.csv）：沙具类别、个体和布局表达的丰富程度
6. 深层图像视图（cnn32.csv）：深度学习模型提取的高层视觉语义
7. 浅层图像视图（vision.csv）：颜色、纹理、边缘和形状等低层视觉信息
8. 语义视图（semantic.csv）：沙盘文本描述或主题内容的语义信息

CSV数据文件路径：py/ai_service/data/（9个文件）

4.3 稀疏自编码器（SSAE）
- 将8类异构视图特征压缩到统一低维空间（32维）
- 隐藏层使用BatchNorm和ReLU激活
- 引入KL散度稀疏约束防止过拟合

4.4 视图MLP + 全局MLP
- 每个视图通过独立两层MLP获得视图特定共识表征
- 所有视图编码拼接后通过共享全局MLP获得全局表征

4.5 对比学习（InfoNCE）
- 各视图共识表征与全局表征L2归一化后计算相似度矩阵
- 以InfoNCE形式构建对比目标
- 拉近同一样本不同表征，拉远不同样本

4.6 自适应加权融合
- 权重通过带温度参数的Softmax计算
- 最小权重下限0.05，防止某个视图被完全忽略
- 最终融合表征作为后续GCN、聚类、异常检测的统一特征基础

4.7 可学习图卷积
- 基于各视图特征分别构建k近邻邻接矩阵（k=15）
- 对每个视图邻接矩阵进行对称归一化
- 通过可学习参数对各视图邻接矩阵加权融合
- 引入可学习矩阵S和自适应阈值τ=0.3对图结构精炼
- Sigmoid(S⊙Â) > τ 筛选有效边
- 两层图卷积得到分类输出

4.8 损失函数
L_total = L_cls + 0.1·L_con + 0.05·L_rec + 0.01·L_sparse + 0.01·L_entropy

- L_cls：带类别权重的交叉熵分类损失，仅在标注样本上计算
- L_con：对比学习损失（InfoNCE）
- L_rec：稀疏自编码器重构损失（MSE）
- L_sparse：KL散度稀疏约束
- L_entropy：自适应权重的熵正则化项

4.9 训练参数
- 280个epoch，优化器Adam，学习率0.001，权重衰减5e-4

================================================================================
五、半监督学习策略
================================================================================

- 总数据集6208个沙盘样本
- 有标签样本2088个
- 标签策略（基于分数）：score≤4→异常，score≥6→正常，中间→无标签
- 训练时随机抽取16.8%有标签样本作为训练标签（约350个）
- 其余有标签样本（约1046个）作为测试集
- 大量无标签样本通过对比学习等自监督信号利用

================================================================================
六、前端显示策略（重要）
================================================================================

6.1 二分类 vs 三分类
- 模型内部：正常/异常 二分类
- 前端展示：正常 / 偏低（需关注） / 偏高（需关注）
- 映射逻辑：基于模型异常概率和分数方向

6.2 温度缩放
- softmax(logits/2.0)，温度=2.0，使概率分布更平滑

6.3 风险分数 = P(abnormal) × 100

6.4 风险等级：低风险（绿）、中风险（橙）、高风险（红）
- 注意：不是"轻度、中度、重度"

6.5 八维心理画像雷达图
维度：行为活跃度、类别丰富度、情感健康度、空间布局、沙具多样性、深层图像表达、视觉色彩表达、语义丰富度
数据来源：各视图特征的百分位均值

6.6 关键心理指标卡片
- 评估分数（正常范围4.5~6.0）
- 沙具多样性（百分位排名）
- 沙具数量（百分位排名）
- 游戏时长（百分位排名）

6.7 概率分布：三个类别的概率值

6.8 心理建议：根据预测结果生成针对性建议

================================================================================
七、异常检测页面
================================================================================

- 算法：孤立森林（Isolation Forest）= 无监督
- 输入：用户选定多个沙盘ID
- 特征：使用模型学习的融合表征（不是原始特征）
- 输出：异常分数 + 正常/异常判定
- 可视化（三图并排一行，span=8）：
  1. 饼图：正常与异常样本占比
  2. 柱状图：异常分数排序，颜色区分程度
  3. 雷达图：异常组vs正常组8个心理维度差异
- 统计概览：总样本数、正常样本数、异常样本数
- 详情表格：含沙盘照片、ID、得分、状态、名称

================================================================================
八、聚类分析页面
================================================================================

- 算法：K-Means（聚类用K-Means，不是GCN）
- 输入：用户选定样本 + 聚类数目
- 特征：多视图融合特征
- 输出：聚类标签、轮廓系数、样本分布、特征对比
- 可视化：分布柱状图、占比饼图、成员详情表
- 轮廓系数评级：优秀、良好、一般、较差

聚类画像分析四个子页面：
1. 聚类算法介绍：SOM、K-Means++、凝聚层次聚类
2. 聚类结果总览：4个折叠面板
3. 聚类群体画像：跳转聆心云3D沙盘数据大屏
4. 聚类个体画像：沙盘列表

十一、答辩常见问题（30题）
================================================================================

背景动机类：
Q1：为什么选沙盘？→ 非言语低压力，减少社会期望偏差
Q2：传统方法问题？→ 量化不足、主观性强、难大规模
Q3：目标用户？→ 校园/医疗/企业

算法模型类：
Q4：模型是什么？→ 多视图融合图卷积模型，8类视图+对比学习+GCN
Q5：为什么8类视图？→ 覆盖沙盘多维度，基于心理学分析维度和特征工程
Q6：什么是半监督？→ 少量有标签+大量无标签，只有16.8%有标签
Q7：对比学习作用？→ 拉近相似表征拉远差异，弥补标注不足
Q8：自适应权重？→ 动态衡量视图贡献，突出有效抑制噪声
Q9：可学习GCN和普通GCN区别？→ 多视图邻接融合+可学习矩阵精炼图结构
Q10：为什么用孤立森林？→ 无监督无需标注，适合标签稀缺
Q11：损失函数？→ 五部分联合（分类+对比+重构+稀疏+熵正则）
Q12：超参数？→ k=15网格搜索，温度参数控制权重平滑度

实验数据类：
Q13：数据集多大？→ 6208样本，16.8%训练标签
Q14：实验结果？→ 准确率93.51%，召回84.35%，F1 87.00%
Q15：召回率为什么低？→ 16.8%标注，边界不确定，可调阈值
Q16：基线对比？→ 消融实验

系统设计类：
Q17：系统架构？→ Vue2+SpringBoot+FastAPI三层分离
Q18：三分类和二分类？→ 模型二分类，前端映射三分类，温度缩放
Q19：聚类算法？→ K-Means，融合特征上聚类，轮廓系数评估
Q20：聆心云关系？→ 独立平台，跳转接入，数据不自动同步

创新应用类：
Q21：创新点？→ 8类视图+多视图融合GCN+16.8%标注训练+半监督无监督互补
Q22：和已有研究比？→ 多模态融合+完整应用链路
Q23：能替代咨询师？→ 不能，辅助筛查工具
Q24：部署过？→ 开发完成可演示，计划合作试用
Q25：应用价值？→ 降低筛查门槛、量化分析、可视化

刁钻问题：
Q26：视图来源？→ 心理学维度+文献+数据集特征
Q27：可解释性？→ 雷达图+特征重要性+百分位排名
Q28：换数据集？→ 框架通用，需重新训练
Q29：标注质量？→ 标准化量表，基于分数软划分
Q30：技术难度？→ 异构视图对齐+极低标注率+可学习图结构
