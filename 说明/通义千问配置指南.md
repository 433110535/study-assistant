## 📝 配置步骤（5 分钟）

### 第 1 步：获取阿里云 API Key

1. **访问控制台**
   ```
   https://dashscope.console.aliyun.com/
   ```

2. **登录/注册**
   - 使用阿里云账号登录（淘宝/支付宝账号可能通用）
   - 或者注册新账号（需要手机号验证）

3. **实名认证**（首次使用需要）
   - 支付宝实名认证（个人用户）
   - 企业认证（企业用户）

4. **创建 API Key**
   - 点击左侧菜单 "API-KEY管理"
   - 点击 "创建新的 API-KEY"
   - 输入名称（如：study-assistant）
   - **复制生成的 API Key**（格式：sk-xxxxx...）

### 第 2 步：配置到项目

打开文件：`E:\比赛项目\智能体\.env`

找到第 7 行：
```bash
DASHSCOPE_API_KEY=your_dashscope_api_key_here
```

替换为（粘贴你的 Key）：
```bash
DASHSCOPE_API_KEY=sk_你复制的Key粘贴在这里
```

保存文件！

### 第 3 步：验证配置

```bash
cd E:\比赛项目\智能体
python test_qwen.py
```

如果看到 `[SUCCESS] 所有测试通过！` 说明配置成功。

### 第 4 步：启动应用

```bash
# 方式 1：使用启动脚本
python start.py

# 方式 2：直接启动 Streamlit
streamlit run frontend/app.py

# 方式 3：Windows 双击
start.bat
```

浏览器自动打开：http://localhost:8501

## 🆘 故障排除

- 解决：编辑 .env 文件，确保 DASHSCOPE_API_KEY= 后面有 Key

**问题 2: 实名认证失败**
- 解决：使用支付宝完成个人实名认证

**问题 3: API Key 无效**
- 解决：重新创建 API Key，旧的 Key 可能已过期

**问题 4: 额度用完**
- 解决：升级账号或等下月重置
